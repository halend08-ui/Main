# Launch / update checklist

Back to [[Roblox Home]]

Run through this before **every** publish.

## Test
- [ ] Studio: *Test > Start* with 2+ players (catches server/client bugs)
- [ ] Device emulator: phone and tablet sizes; UI fits and buttons are tappable
- [ ] No red errors in Output, or in the F9 console in the live game
- [ ] Save → leave → rejoin restores progress
- [ ] Every new level can be beaten without buying anything

## Money
- [ ] Every Product and Pass ID is set in `ObbyConfig` (none left at `0`)
- [ ] Buy Skip once with a real account and confirm it's granted exactly once
- [ ] Passes are "On Sale"

## Page
- [ ] Title/description mention the update (`[UPDATE 9]`)
- [ ] New thumbnail showing the new content
- [ ] Update log / pop-up in the game

## After publishing
- [ ] Shut down old servers or let them migrate (Creator Hub > Servers), so new content reaches everyone
- [ ] Post a Short or clip of the new content
- [ ] Add an entry to [[Session Log]]
- [ ] Check analytics after 3 and 7 days, and note the results in [[Grow an Obby - Backlog]]
