- **`commerce-os/`** — the autonomous Shopify commerce operating system. Its constitution is
  imported below and is binding for all work in this repo.
- `src/`, `index.html`, `vite.config.js`, root `package.json` — an unrelated "Meridian" React demo.
  Do not modify it as part of commerce work.
